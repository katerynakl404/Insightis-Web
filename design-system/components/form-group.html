Form group

The vertical wrapper that stitches a field to its label, hint and validation message — defined in ds/components/form-group.css. A column stack with a small gap; the label carries an optional required asterisk and the message can flip to an error tone. Used to compose the contact and demo-request forms.

Label + input + hint

We'll only use this to send your certified answer. 
<div class="ins-form-group">
  <label class="ins-form-group__label" for="fg-email">Work email</label>
  <input class="ins-input" id="fg-email" type="email" placeholder="you@company.com">
  <span class="ins-form-group__hint">We'll only use this to send your certified answer.</span>
</div>

Required label

<div class="ins-form-group">
  <label class="ins-form-group__label ins-form-group__label--required" for="fg-company">Company</label>
  <input class="ins-input" id="fg-company" type="text" placeholder="Acme Inc.">
</div>

Error message

Please use your company email — free inboxes aren't supported. 
<div class="ins-form-group">
  <label class="ins-form-group__label ins-form-group__label--required" for="fg-err">Work email</label>
  <input class="ins-input is-error" id="fg-err" type="email" value="ceo@gmail.com" aria-invalid="true">
  <span class="ins-form-group__message ins-form-group__message--error">Please use your company email…</span>
</div>

Classes

ClassUse
.ins-form-groupColumn flex wrapper with a small gap between label, control and message.
.ins-form-group__label14px medium heading-colour label.
.ins-form-group__label--requiredAppends a red required asterisk.
.ins-form-group__hint12px inactive helper text below the field.
.ins-form-group__message12px validation / status line (neutral by default).
.ins-form-group__message--errorFlips the message to the error tone.

Usage

Built from the ds/components/form-group.css API and composed with .ins-input / .ins-select / .ins-textarea to assemble the contact and demo-request forms. Field labels mirror the real onboarding flow — work email, company, and team audience.
