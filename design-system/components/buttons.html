Button

Five variants (primary / secondary / ghost / icon / link), three sizes (32 / 40 / 48), and every state. Composed by src/components/Button.jsx and used site-wide — the "Sign Up Free" navbar CTA, hero "Start free" buttons, connector-card "Sign in" and the blog "Read more". Every trailing icon is an arrow that nudges right on hover.

Site convention: sm on connector cards ("Sign in"), md in body CTAs, lg in page heros.

Rounding variants

Default is a full pill. Override with --radius-sm / md / lg / pill when a squarer control is needed.

Classes

ClassUse
.ins-btnBase pill button — 40px tall, inline-flex, wide letter-spacing.
.ins-btn--primaryTeal fill, the main site CTA ("Start free", "Sign Up Free").
.ins-btn--secondaryOutlined / bordered button ("Sign in", "See pricing").
.ins-btn--ghostTransparent; background appears only on hover/active.
.ins-btn--iconSquare icon-only button (40px; 44×44 min on mobile). Needs aria-label.
.ins-btn--linkInline text link with underline at 30% opacity; intensifies on hover.
.ins-btn--sm / --md / --lgSizes: 32 / 40 / 48px tall (icon scales 12 / 16 / 20px).
.ins-btn--radius-sm / md / lg / pillOverride the default pill rounding.
.ins-btn__iconIcon slot; sized consistently across button sizes.
.ins-btn__icon--leadingIcon before the label (negative right margin tightens the gap).
.ins-btn__icon--trailingIcon after the label; nudges 3px right on hover/focus.
.is-loadingLoading — hides label, shows a centered spinner, preserves width.
:disabled / [aria-disabled="true"]Disabled — no pointer events; use aria-disabled on anchor buttons.
