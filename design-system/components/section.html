Section

The DS section wrapper that sets vertical rhythm and centres content at a fixed max-width. <Section> renders .ins-section plus a .ins-section__inner child, tokenizing the py-* max-w-* mx-auto px-6 Tailwind pattern repeated 30+ times across the site. Padding, container width and tone are opt-in modifiers.

Base

Bare .ins-section wraps its content in .ins-section__inner, which caps width at --ins-container-max, centres it and applies responsive horizontal padding. The dashed outline below marks the section box so the vertical padding is visible.

Content sits inside .ins-section__inner — centred, max-width capped, padded. 
<section class="ins-section">
  <div class="ins-section__inner">
    …content…
  </div>
</section>

Padding tiers

--sm 48 px, --md 64 px, --lg 80 px (canonical), --xl 96 px on mobile; each bumps one tier larger from the 768 px breakpoint up (lg→96, xl→120). Bare .ins-section alone keeps the legacy 80/96 default.

Container widths

The container modifier caps .ins-section__inner max-width: --container-5xl 1024 px, --container-6xl 1152 px, --container-7xl 1280 px (canonical). The teal-tinted bars below show each inner's rendered width.

Tones

Default tone is transparent. --tint layers a subtle teal radial-glow background (top + bottom); --dark fills with --ins-surface-elevated, a deeper surface than the page background.

ins-section--tint — teal radial glow
ins-section--dark — elevated surface
