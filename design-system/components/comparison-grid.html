Comparison grid

A two-column "before / after" grid — one column per side, each a bordered card of checklist rows with a teal check or red ✕ mark. Column modifiers set the tone: --highlight (brand tint + glow for the winning side), --negative (red tint for the "before" side). The bare .ins-comparison grid also wraps the "Generic AI vs Insightis" glow cards in src/pages/ai-chat.jsx.

Before / after

The grid stacks to one column on mobile, splits to two from the md breakpoint. Left column is the painful status quo (--negative, red ✕ marks); right is Insightis (--highlight, teal checks).
