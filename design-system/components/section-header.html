Section Header

The eyebrow + heading + lede triplet that opens nearly every marketing section. <SectionHeader> composes .ins-eyebrow (optionally --pill), a .ins-text-display heading and a .ins-text-body-lg lede inside a flex wrapper, replacing 22+ hand-rolled copies across src/pages/*.jsx. Alignment and spacing come from inline layout styles; every visible token is a real class.

Centered (default)

Default align="center": wrapper is a centred column capped at 760 px, lede capped at 640 px. Eyebrow defaults to the pill variant. Heading renders <h2> at the .ins-text-display scale.

align="left" flips the wrapper to align-items:flex-start, drops the max-width cap (max-width:none) and removes the auto side margins; the lede loses its 640 px cap too.

Size + heading level (md vs lg)

Both size="md" (default, <h2>) and size="lg" (hero, paired with as="h1") render the heading at the same .ins-text-display scale — per the component, size now only tunes letter-spacing and does not change the class. The as prop swaps the underlying heading tag for correct document outline.

Classes

ClassUse
.ins-eyebrowUppercase label above the heading (auto ✦ star). Rendered when the eyebrow prop is set.
.ins-eyebrow--pillAdded when eyebrowVariant="pill" (the default) — teal-tinted pill.
.ins-text-displayThe heading, for both size values (36 px mobile / 48 px desktop). Tag set by as.
.ins-text-body-lgThe lede paragraph. Rendered when the lede prop is set.

Source: src/components/SectionHeader.jsx — props eyebrow, title, lede, align (center/left), size (md/lg), as (h1/h2/h3), eyebrowVariant (pill/plain). Layout (flex column, 16 px gap, max-width caps, alignment) is applied via inline styles; only the eyebrow, heading and lede carry DS classes.
