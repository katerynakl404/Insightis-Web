Table

Bordered, horizontally-scrollable data table. The .ins-table-wrap supplies the rounded border and overflow; .ins-table the collapsed grid with sticky uppercase headers, per-row bottom borders and a hover row. Modifiers add zebra striping (--striped) and denser padding (--compact). Copy below is the real plan comparison from src/pages/pricing.jsx / src/data/pricing.js.

Default

Always wrap the table in .ins-table-wrap — that's what rounds the corners and lets the table scroll on narrow screens. Headers stick to the top of the scroll area.
