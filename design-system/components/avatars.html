Component

Avatar

Circular user token holding an image or initials. Five sizes (xs 16 → xl 64), an optional corner status dot in four states, and an overlapping avatar-group stack.

Sizes

xs · sm · md (default) · lg · xl. Type scales with the badge.

MK MK MK MK MK 
<span class="ins-avatar ins-avatar--xs">MK</span>
<span class="ins-avatar ins-avatar--sm">MK</span>
<span class="ins-avatar ins-avatar--md">MK</span>
<span class="ins-avatar ins-avatar--lg">MK</span>
<span class="ins-avatar ins-avatar--xl">MK</span>

Image

An <img> child fills and crops (object-fit:cover) to the circle.

<span class="ins-avatar ins-avatar--lg">
  <img src="/avatars/priya.jpg" alt="Priya N.">
</span>

Status dot

Add .ins-avatar__status as a child with a state modifier. The dot scales with avatar size.

AL AL AL AL 
<span class="ins-avatar ins-avatar--lg">AL
  <span class="ins-avatar__status ins-avatar__status--success"></span>
</span>

<!-- States: --success · --warning · --error · --offline -->

Group (overlapping stack)

.ins-avatar-group overlaps children by 8px and rings each in the page colour.

  <span class="ins-avatar ins-avatar--md">+4</span>
