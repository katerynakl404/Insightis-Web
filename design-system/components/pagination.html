Pagination

Numbered page control for long lists — 32px square items, a teal fill on the current page (aria-current="page"), dimmed prev/next when they run out, and an … ellipsis for skipped ranges. Intended for the Blog index and other paginated archives. Built from the component CSS API.

Default (mid-range)

Page 2 of 12. Prev / Next are enabled; page 2 carries aria-current="page"; the gap before the last page uses .ins-pagination__ellipsis.

</nav>

First page (Prev disabled)

On page 1 the Previous control is disabled — dimmed and non-interactive.

Classes

ClassUse
.ins-paginationInline-flex row wrapping the items with a small gap.
.ins-pagination__itemSquare 32px page control (button or link). Tinted surface on hover.
.ins-pagination__item[aria-current="page"], .ins-pagination__item.is-activeCurrent page — solid teal fill, white text.
.ins-pagination__item:disabledDisabled control (e.g. Prev on the first page) — dimmed, not-allowed cursor.
.ins-pagination__ellipsisNon-interactive … gap for skipped page ranges.
