Metrics catalog

The Platform / Semantic-layer "Metrics catalog" organism (src/components/MetricsCatalog.jsx): a two-up layout with a metric grid on the left and a detail panel on the right. Every string is the shipped metric library's own text. The grid is a single-select listbox and sets the height; the detail panel stretches to match it and scrolls inside, so the section never changes shape when you pick a different metric. Source-family tabs (rendered with the DS Chip component) sit above the grid.

Grid + detail panel

The grid below shows the CRM source family with its first card selected. Card logos are painted from the connector sprite via .ins-connector-logo. At ≥1024px the detail panel is absolutely positioned to match the grid height; the three inner blocks (description, formula, ask box) keep fixed heights so they line up at the same baseline for every metric.
