Checkbox / Radio / Toggle

Three selection controls sharing one ds/components/checkbox-radio-toggle.css. Each hides the native input and draws a custom box / dot / track that checks in teal. Rows are 44px tall on mobile for touch, collapsing to auto on desktop. Focus rings come from the visually-hidden input's :focus-visible.

Usage

Built from the ds/components/checkbox-radio-toggle.css API (no bespoke JSX component). Labels use real product settings — metric digests, connector notifications, monthly / annual billing, real-time sync and SSO enforcement.
