Badge

Small inline pill — status labels, interactive filter tabs, counts, trend numbers and removable tags. Composed by src/components/Chip.jsx. Live instances: the navbar "Coming Soon" (src/components/Header.jsx), category filter tabs on Integrations / AI-chat / Metrics catalog, and the "Insightis" vs "Generic AI" comparison chips.

Classes

ClassUse
.ins-badgeBase pill — inline-flex, 11px medium, pill radius, transparent border.
.ins-badge--success / --warning / --error / --infoStatus tones (green / amber / red / blue).
.ins-badge--planned / --shippedRoadmap tones (planned / shipped).
.ins-badge--brandTeal brand-tint with brand border — "Coming Soon", "Insightis".
.ins-badge--tabInteractive filter chip; aria-pressed="true" = active (brand-tinted).
.ins-badge--countElevated-surface count pill, min 20px, centered.
.ins-badge--trendMono font + tabular figures for deltas (pair with a tone).
.ins-badge--metric-pillMono card-surface pill for a metric name / value.
.ins-badge__dot6px status dot in currentColor before the label.
.ins-badge__dot--pulseAdds an animated expanding ring (live status).
.ins-badge__removeTrailing close (×) button; tightens chip padding via :has().

Usage

Composed by src/components/Chip.jsx. Live: ins-badge--brand "Coming Soon" in src/components/Header.jsx; ins-badge--tab category filters in src/pages/integrations.jsx, ai-chat.jsx and src/components/MetricsCatalog.jsx (labels "RevOps & BizOps", "Finance", …); the variant="error" dot "Generic AI" vs variant="brand" dot dotPulse "Insightis" pair documented in src/components/README.md. Status, count, trend and metric-pill variants are built from the badge.css API.
