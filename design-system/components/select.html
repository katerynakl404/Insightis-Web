Select

Native <select> styled to match Input — defined in ds/components/input.css. Native chevron is suppressed (appearance:none) and replaced by an inline SVG data-URI arrow with extra right padding. Same 40px height, three sizes, and disabled > error > focus > hover state priority as the other fields.

Classes

ClassUse
.ins-selectBase native select — suppresses the OS chevron, draws its own SVG arrow with right padding.
.ins-select--sm / --lg32px (14px text) / 48px sizes.
.is-errorError — red border + red ring; pair with aria-invalid.
:disabledTransparent fill, muted border/text, not-allowed cursor.
:hover / :focus-visibleProminent border on hover; teal border + subtle ring on focus (global outline suppressed).

Usage

Built from the shared ds/components/input.css Select rules. Option copy mirrors real product taxonomy — team audiences, warehouses (Snowflake / BigQuery / Redshift) and connectors (Stripe / HubSpot / Salesforce) used across the Integrations and Solutions pages.
