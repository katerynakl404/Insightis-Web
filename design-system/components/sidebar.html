Sidebar

Docs-style, non-collapsable table-of-contents rail. Grouped links each sit on a 1px left rail for scanability; the active item gets a teal 2px rail and brand-tint background. Fixed 240px column, hidden below 1024px. The Docs experience (src/pages/docs.jsx) uses its own .ins-doc-nav tree — this page is the DS reference for the flat .ins-sidebar pattern built from the CSS API.

Sidebar (one active item)

Two groups. The active link (.is-active, equivalent to aria-current="page") is Semantic Layer. Because the rail is display:none below 1024px, the specimen is wrapped in a fixed-width host so it renders at any storybook width.
