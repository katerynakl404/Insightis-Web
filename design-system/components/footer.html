Footer

Site-wide footer: a brand block plus five link columns that collapse from 5 → 3 → 2 across breakpoints, over a bottom bar with the copyright and social icons. External links carry a small outbound arrow via .ins-footer__link--external. Rendered on every page (the live site's src/components/Footer.jsx styles it with utilities; this page is the DS reference built from the CSS API with the footer's real content).
