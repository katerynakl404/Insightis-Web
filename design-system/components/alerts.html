Alert & Toast

Inline status message with a leading 20×20 icon, optional title and dismiss button, in four semantic tones. The ins-toast variant reuses the same markup but floats fixed (bottom-center on mobile, bottom-right ≥768px); --compact drops the title for single-line ephemeral feedback.

Tones

Info · success · warning · error. Each tone tints the background and colours the icon; all icons use 1.5 stroke with rounded caps.

Classes

ClassUse
.ins-alertBase row: icon + content, bordered, 14px body text.
.ins-alert__iconLeading 20×20 SVG, aligned to the first line; forces 1.5 stroke + rounded caps.
.ins-alert__titleOptional bold heading above the description.
.ins-alert__closeTrailing dismiss button, pinned right (margin-left:auto).
.ins-alert--infoInfo tone — tinted background, info-coloured icon.
.ins-alert--successSuccess tone.
.ins-alert--warningWarning tone.
.ins-alert--errorError tone.
.ins-toastFloats the alert fixed (bottom-center → bottom-right ≥768px) with elevated surface + shadow.
.ins-toast--compactSingle-line variant: hides the title, smaller padding, 16px icon.
