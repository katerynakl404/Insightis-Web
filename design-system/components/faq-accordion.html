FAQ Accordion

Chevron-toggle accordion, one row per Q&A. The open row (.is-open) gets a teal-tinted border and a rotated highlighted chevron; closed rows use the default surface border. Used on Solutions pages and Pricing.

Classes

ClassUse
.ins-faqVertical stack of rows with a small gap.
.ins-faq__rowOne Q&A card: dark surface, subtle border, clipped corners.
.ins-faq__row.is-openOpen state — teal-tinted border; reveals the answer and rotates the chevron.
.ins-faq__questionFull-width toggle button (question text + chevron). Carries aria-expanded.
.ins-faq__chevronDown chevron SVG; rotates 180° and turns teal when the row is open.
.ins-faq__answerAnswer body — pair with .ins-text-body for type; this class supplies layout only.
