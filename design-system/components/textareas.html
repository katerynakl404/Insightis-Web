Textarea

Multi-line field for longer input — demo requests, support messages, metric descriptions. Defined alongside Input and Select in ds/components/input.css: a 96px minimum height, vertical-only resize, and a resizer overlay pushed inward so it never clips the focus ring. Same disabled > error > focus > hover state priority.

In a form group

Pair with .ins-form-group for a label, hint and validation message — the pattern used on the contact / demo-request forms.

We'll route your question to the right specialist. 
<div class="ins-form-group">
  <label class="ins-form-group__label ins-form-group__label--required" for="tx-msg">What would you like to ask Insightis?</label>
  <textarea class="ins-textarea" id="tx-msg" placeholder="e.g. Why did MRR drop last week?"></textarea>
  <span class="ins-form-group__hint">We'll route your question to the right specialist.</span>
</div>

Classes

ClassUse
.ins-textareaBase multi-line field — 96px min height, relaxed line-height, vertical resize.
.ins-textarea--sm / --lgSmaller (14px text) / larger padding variants.
.is-errorError — red border + red ring; pair with aria-invalid.
.is-filledKeeps a value legible when the field is also disabled.
:disabledTransparent fill, muted border and text; works on any surface.
::-webkit-resizerResizer overlay is inset so it never clips the animated focus ring.

Usage

Built from the shared ds/components/input.css Textarea rules (no bespoke JSX component — composed inline inside contact / demo-request forms with .ins-form-group).
