Accordion

A stack of expandable rows on the card surface. Each .ins-accordion__item toggles aria-expanded, which rotates the chevron and animates the panel's max-height. storybook.js wires every .ins-accordion: single-open by default, or set data-allow-multiple="true" to keep several open. (For the marketing FAQ styling see the FAQ accordion.)

Single-open (default)

Opening one row closes the others. The open item carries aria-expanded="true"; a focused trigger lifts the whole item's focus ring via :has().

Classes

Class / attributeUse
.ins-accordionVertical stack of items. storybook.js binds the toggle here.
[data-allow-multiple="true"]On the root — allows several items open at once (default: single-open).
.ins-accordion__itemOne row on the card surface. State lives in aria-expanded (or .is-open).
.ins-accordion__triggerFull-width toggle button: heading text + chevron, space-between.
.ins-accordion__icon20px chevron; rotates 180° when the item is expanded.
.ins-accordion__panelAnswer body; animates from max-height:0 to open with bottom padding.
