Divider

A one-pixel rule in the default border color. Horizontal by default, with --vertical for splitting inline content and --labeled for a centered caption between two rules (e.g. an "or" separator in forms and CTAs).

Horizontal

Default: a full-width border-default rule with xl vertical margin. Use <hr> for a real semantic separator.

Vertical

--vertical stretches to its flex parent's height and adds horizontal margin. Put it between inline items in a flex row.

Labeled

--labeled flexes a caption between two rules that fill the remaining space. The label is inactive-color, 12px. Common "or" separator.
