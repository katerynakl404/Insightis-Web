Connector gallery

The connector surfaces used across Resources / Connectors and Platform / Integrations. Two layouts share one frosted "Sign in to connect" hover overlay: the square-tile .connector-grid gallery, and the horizontal .connector-card (opt into the overlay with .has-overlay). Logos are painted from a single normalized sprite sheet via .ins-connector-logo — a fixed box whose mark is positioned by --logo-x and scaled up to a common footprint by --logo-scale; dark marks are re-tinted with .is-dark.

Sprite marks — .ins-connector-logo

Every logo is one cell of /connectors/sprite.svg. The variant class (e.g. .salesforce) sets the horizontal cell offset (--logo-x) and a scale-up factor (--logo-scale) that normalizes each mark to a common footprint. Size is driven by --ins-connector-size. Dark / low-contrast marks add .is-dark, which inverts lightness while keeping hue so a black wordmark reads as white on the dark theme.

.is-dark — inverted marks:

Classes

ClassUse
.connector-gridResponsive logo grid: 6 columns, stepping down to 2 as the viewport narrows.
.connector-tileSquare 1:1 tile (logo above name). Hover lights the border and reveals the overlay; entrance tileIn animation.
.connector-faceThe logo + name stack; dims and scales back slightly while the overlay is shown.
.connector-logo40px bare logo slot (no chip) inside a tile; img children fit to it.
.connector-nameTile caption; clamps to two lines and reserves the full two-line height so rows align.
.connector-cardHorizontal card: icon + name (+ optional description). Used by Integrations and Solutions.
.connector-card.has-overlayOpts the card into the shared frosted hover overlay (dims its content on hover).
.connector-icon36px rounded icon box; holds the mono abbreviation fallback when a connector has no sprite/logo.
.connector-overlayFrosted, blurred overlay (backdrop-filter) with the sign-in CTA; opacity:0 + inert until hover.
.connector-overlay .banner-labelOptional small uppercase label above the overlay button.
.ins-connector-logoSprite box. One cell of /connectors/sprite.svg, painted on ::before; size via --ins-connector-size.
.ins-connector-logo.slugPer-connector variant (e.g. .salesforce, .hubspot, .stripe) setting --logo-x + --logo-scale.
.ins-connector-logo.is-darkInverts lightness (keeps hue) so dark / low-contrast marks read on the dark theme. .amazonrds.is-dark further boosts saturation.
