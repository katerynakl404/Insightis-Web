Breadcrumbs

Compact trail showing where a page sits in the hierarchy. Anchor crumbs navigate; a plain <span> marks the current page with aria-current="page"; a <button> crumb variant is used for SPA navigation. Live on Docs (src/pages/docs.jsx) and every blog article (src/components/BlogPost.jsx).

Blog article (link crumbs)

Exactly the trail every article renders — Home / Blog — with the article title intentionally omitted. Wrapped in a <div role="navigation"> to sidestep the global nav {…} prose rule.

Home / Blog 
<div class="ins-breadcrumbs" role="navigation" aria-label="Breadcrumb">
  <span class="ins-breadcrumbs__item"><a href="/">Home</a></span>
  <span class="ins-breadcrumbs__separator" aria-hidden="true">/</span>
  <span class="ins-breadcrumbs__item"><a href="/blog/">Blog</a></span>
</div>

Docs trail (with current page)

The Docs breadcrumb: navigable crumbs plus a final non-link crumb carrying aria-current="page".

Docs / Platform / Semantic Layer 
<div class="ins-breadcrumbs" role="navigation" aria-label="Breadcrumb">
  <span class="ins-breadcrumbs__item"><a href="#">Docs</a></span>
  <span class="ins-breadcrumbs__separator" aria-hidden="true">/</span>
  <span class="ins-breadcrumbs__item"><a href="#">Platform</a></span>
  <span class="ins-breadcrumbs__separator" aria-hidden="true">/</span>
  <span class="ins-breadcrumbs__item" aria-current="page">Semantic Layer</span>
</div>

Button crumbs (SPA navigation)

When crumbs drive client-side routing rather than full page loads, Docs renders them as <button class="ins-breadcrumbs__item"> — reset to look identical to the link crumbs.

/ / Connect a data source 
<div class="ins-breadcrumbs" role="navigation" aria-label="Breadcrumb">
  <button type="button" class="ins-breadcrumbs__item">Docs</button>
  <span class="ins-breadcrumbs__separator" aria-hidden="true">/</span>
  <button type="button" class="ins-breadcrumbs__item">Guides</button>
  <span class="ins-breadcrumbs__separator" aria-hidden="true">/</span>
  <span class="ins-breadcrumbs__item" aria-current="page">Connect a data source</span>
</div>

Classes

ClassUse
.ins-breadcrumbsFlex, wrapping trail; small muted type.
.ins-breadcrumbs__itemOne crumb. As a <span> wrapping an <a> for links, or a bare span for the current page.
.ins-breadcrumbs__item aLink crumb — body color, teal on hover.
.ins-breadcrumbs__item[aria-current="page"]Current page crumb — body color, not a link.
button.ins-breadcrumbs__itemClickable crumb as a reset <button> (SPA navigation); teal on hover.
.ins-breadcrumbs__separatorMuted / divider between crumbs (mark aria-hidden).
