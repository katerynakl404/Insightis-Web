Component

Kbd

A single keycap for keyboard hints. The bare <kbd> element and the .ins-kbd class are styled identically: mono, 20px tall, elevated surface with a subtle shadow. Combine several with a "+" for shortcuts.

Single keys

Any key label — letters, symbols or named keys. Min-width keeps single characters square.

K / Esc Enter ⌘ ⇧ 
<kbd>K</kbd>
<kbd>/</kbd>
<kbd>Esc</kbd>
<kbd>Enter</kbd>
<kbd>⌘</kbd>

Shortcut combinations

Separate keycaps with a plain "+" so each key reads as its own cap. The .ins-kbd class produces the same result on any element.

Open command palette ⌘+K
Focus search /
Run query ⌘+Enter 
<span>Open command palette</span> <kbd>⌘</kbd>+<kbd>K</kbd>

<!-- Class form on any element -->
<span class="ins-kbd">⌘</span>+<span class="ins-kbd">Enter</span>
