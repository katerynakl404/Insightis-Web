Code

Monospace code display for docs and the blog. Inline .ins-code-inline (bare <code> gets the same treatment) for snippets in a sentence; .ins-code-block for fenced blocks, with an optional __lang tag and an opt-in copy button (data-copy="true", wired by storybook.js). Distinct from the code chip, which is the marketing query/answer widget.

Inline code

A bare <code> element already carries the inline style; .ins-code-inline is the explicit hook.

Insightis reads your models directly — reference a metric like monthly_churn or a table like stripe.subscriptions and it resolves through the Semantic Layer.

Code block

Container surface with horizontal scroll. Nest a <pre><code>; the inner <code> resets to transparent so it reads as one panel.

-- What the Semantic Layer runs for "What's our churn rate?"
SELECT date_trunc('month', canceled_at) AS month,
       count(*) AS churned
FROM stripe.subscriptions
WHERE canceled_at IS NOT NULL
GROUP BY 1
ORDER BY 1 DESC;

With language tag & copy button

Add .ins-code-block__lang for the top-right language label, and data-copy="true" on the block to have storybook.js inject a working copy button (padding shifts to make room for both).

bash 
npm install @insightis/sdk

# Ask your first question
insightis ask "What's our churn rate this month?"

</div>

Classes

Class / attributeUse
.ins-code-inline / codeInline mono snippet: card surface, subtle border, small radius. Bare <code> inherits it.
.ins-code-blockFenced block: container surface, border, horizontal scroll. Nest <pre><code>.
.ins-code-block__langAbsolutely-positioned uppercase language tag, top-right.
[data-copy="true"]On the block — storybook.js injects a copy button and reserves padding for it.
.ins-code-block__copyThe injected copy button; turns success-color on copy.
