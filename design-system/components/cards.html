Card

The dark bordered surface every panel on the site is built from. A bare .ins-card plus composable modifiers: structural (--feature, --pricing, --metric, --connector), decorative (--accent, --glow), and interaction (--interactive, --selected). Standalone shells .ins-feature-card, .ins-article-card and .ins-prompt-card carry their own hover. Rendered through src/components/Card.jsx.

Base card

Surface + border + --ins-radius-card + --ins-space-xl padding. Compose the header slots (__eyebrow, __title, __body) inside.

Glow — brand, error & console

Opaque brand-tinted surface with a top gradient hairline (::before). --glow--brand adds the teal glow shadow; --glow--error restyles to red. The optional __header shows a glowing dot; __console is the mono answer panel. This exact pairing is the "Generic AI vs Insightis" block in src/pages/ai-chat.jsx.

Generic AI

Insightis
> What's our churn rate? Your churn rate in March was 2.1% — down from 2.8% in February. Main driver: Starter plan (↓ 0.9pp).

Classes

ClassUse
.ins-cardBase surface: card background, default border, card radius, xl padding.
.ins-card__eyebrowUppercase 11px highlight label above the title.
.ins-card__title16px/600 heading.
.ins-card__body14px body text.
.ins-card__descRelaxed body copy — forces body color inside glow/branded cards so it doesn't inherit the header tint.
.ins-card--interactivePointer + desktop hover-lift + focus ring. For clickable cards.
.ins-card--selectedBrand border + brand tint (chosen plan / connector).
.ins-card--featureStructural feature-card hook (currently a pass-through atom).
.ins-card--pricingFlex column; __body flexes and the .ins-btn pins to the baseline.
.ins-card__price36px/700 price headline (pricing cards).
.ins-card--accent / --accent-topTop teal rail via inset box-shadow + extra top padding.
.ins-card--glowOpaque brand-tint surface, brand border, top gradient hairline (::before).
.ins-card--glow--brandAdds the teal glow shadow.
.ins-card--glow--errorRed variant — restates the surface as opaque red tint with error border + glow.
.ins-card__headerBrand-colored inline header with a glowing dot (glow cards).
.ins-card__consoleMono dark answer panel inside a card.
.ins-card--metricCompact stat cell: __metric-label (mono) + __metric-value (tabular).
.ins-card--connectorSmall left-aligned icon tile (integrations gallery).
.ins-feature-cardStandalone shell: top teal rail, 16px radius, translucent surface.
.ins-feature-card--interactiveWhole card becomes a link — teal hover border + faint tint + focus ring.
.ins-article-cardBlog-index / related-article link shell (cover-on-top, hover-lift).
.ins-prompt-cardTranslucent prompt / product-teams feature shell with teal hover.

The .ins-stat-strip metric band also lives in card.css — see the Stat / KPI page.
