Steps Process

Horizontal numbered process used in the "How it works" sections (AI Chat, Integrations, Semantic Layer). Each cell is a numbered teal circle over a title, body and an optional inline CodeChip example; a faint connector line joins consecutive circles. Set --ins-steps-count to the number of steps. Responsive: N-up desktop → 2-up tablet (connectors hidden) → 1-up mobile.

Process (3 steps)

01

You ask

Type any business question in plain English — the same way you would ask a colleague. No SQL, no dashboards, no analyst required.

"Which acquisition channel has the best CAC this quarter?"
02

AI Engine goes to work

Insightis validates and analyzes data across every connected source, applying your business logic for accurate, grounded results.

CRM + payments + product data → validated insight
03

You get a precise answer

Get an instant answer with visualization and suggested follow-ups. Save any answer as a live report in one click — no BI tool required.

Answer + chart + "Why did this change?" suggestion
