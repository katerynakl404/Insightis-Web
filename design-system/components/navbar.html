Navbar

Sticky glass capsule that carries the brand, the primary nav (Platform / Solutions / Resources / Pricing) and the sign-in / start-for-free CTAs. It composes .ins-capsule for the pill shell, so adopting markup must carry both classes: class="ins-capsule ins-navbar". A sibling .ins-navbar-menu panel drops the mega-menu beneath the bar without resizing it. The live header (src/components/Header.jsx) currently styles itself inline and does not consume these classes — this page is the canonical DS reference built from the CSS API using the header's real content.

Navbar (default)

The full bar: brand, link row (Pricing is aria-current="page" here) and the two CTAs. Links collapse below 1024px, where the .ins-navbar__mobile-toggle takes over.

Classes

ClassUse
.ins-navbarNavbar-specific layer over .ins-capsule — sticky, glass background, 52/56px height, fixed gutter. Add alongside .ins-capsule.
.ins-navbar.is-dropdown-openDropdown-open state; the bar keeps its pill shape (the menu panel is an independent sibling).
.ins-navbar__brandLogo + wordmark lockup at the left.
.ins-navbar__linksCenter link row. Hidden below 1024px.
.ins-navbar__linkPill nav item (button or link). Takes aria-current="page" (active) and aria-expanded="true" (open dropdown).
.ins-navbar__link-chevronSmall chevron on dropdown triggers; rotates 180° when aria-expanded="true".
.ins-navbar__mobile-toggleHamburger button shown below 1024px; hidden on desktop.
.ins-navbar-menuFloating mega-menu panel below the capsule; blends into the bar (no top border, negative offset).
.ins-navbar-menu__gridTwo-column grid of menu sections.
.ins-navbar-menu__headingUppercase section label (PRODUCT / FEATURES).
.ins-navbar-menu__itemOne linked row: icon + label + description; tinted hover.
.ins-navbar-menu__item-icon32px brand-tinted icon tile.
.ins-navbar-menu__item-labelItem title.
.ins-navbar-menu__item-descItem supporting copy.
