Marquee

Decorative horizontal auto-scroller with edge fade masks. The track is duplicated and translated -50% for a seamless loop; the animation only runs at ≥768px and pauses on hover. storybook.js also pauses it while off-screen (perf). The intended use is the "200+ Integrations" connector strip (src/components/IntegrationsStrip.jsx, which currently ships its own .marquee-* variant) — this page is the DS reference built from the .ins-marquee CSS API with the real connector catalog.

Notes

The pill chips above are demo content styled with DS tokens; the marquee component itself only provides the two classes below. Below 768px the animation is disabled and the row simply overflows (decorative).

ClassUse
.ins-marqueeOverflow-clipped viewport with left/right transparent fade masks.
.ins-marquee__trackInline-flex row of items; animates a continuous -50% translate at ≥768px, pausing on hover. Must contain two copies of the content for a seamless loop.
