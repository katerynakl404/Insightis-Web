Segmented control

A pill-shaped group of mutually-exclusive options — one card-surface rail with a 3px inset, the selected item lifting to the elevated surface. Defined in ds/components/segmented-control.css. Used for compact binary/ternary switches such as monthly / annual billing on Pricing.

Billing period (two options)

<div class="ins-segmented" role="tablist" aria-label="Billing period">
  <button class="ins-segmented__item is-active" role="tab" aria-selected="true">Monthly</button>
  <button class="ins-segmented__item" role="tab" aria-selected="false">Annual</button>
</div>

Three options

<div class="ins-segmented" role="tablist" aria-label="Date range">
  <button class="ins-segmented__item" role="tab" aria-selected="false">7 days</button>
  <button class="ins-segmented__item is-active" role="tab" aria-selected="true">30 days</button>
  <button class="ins-segmented__item" role="tab" aria-selected="false">Quarter</button>
</div>

Selection via aria-selected

The active item can be marked with either .is-active or aria-selected="true" — both resolve to the elevated-surface treatment, so ARIA tabs need no extra class.

<button class="ins-segmented__item" role="tab" aria-selected="true">Chart</button>
<button class="ins-segmented__item" role="tab" aria-selected="false">Table</button>
<button class="ins-segmented__item" role="tab" aria-selected="false">SQL</button>

Classes

ClassUse
.ins-segmentedInline-flex rail — card surface, bordered, pill radius, 3px inner padding.
.ins-segmented__itemOne option button — transparent, body text; brightens to heading text on hover.
.ins-segmented__item.is-activeSelected — elevated surface + heading text.
.ins-segmented__item[aria-selected="true"]Same selected treatment for ARIA tab semantics.

Usage

Built from the ds/components/segmented-control.css API. Note: category filters on Integrations / AI-chat / Metrics catalog use the interactive .ins-badge--tab chip instead — reach for a segmented control for compact binary/ternary switches like billing period or a chart/table/SQL view toggle.
