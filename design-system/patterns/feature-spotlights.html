Class / attributeUse
[data-spotlight-grid]Two-column grid (1fr 1fr, gap:var(--ins-size-16)); collapses to one column ≤900px (app-blocks.css).
[data-spotlight-text] · [data-spotlight-visual]The text and visual halves. order swaps on odd rows so the visual alternates left/right; the visual is a fixed 440px tall.
.ins-eyebrow.ins-eyebrow--pillPer-row mono eyebrow pill above the row heading.
.ins-text-h2 · .ins-text-body-lgRow heading and lede type scales.
.ins-cardStand-in visual. On the real pages this slot holds a per-page mockup node (SpotlightChat, SpotlightSemantic, …).
