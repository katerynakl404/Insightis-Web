Pricing feature matrix

The sectioned plan-comparison table below the pricing cards on /pricing, rendered by the FeatureComparison section of src/pages/pricing.jsx. Feature rows are grouped by category; columns are the three plans (Free / Starter / Pro) from src/data/pricing.js; cells resolve to a CheckIcon, an em-dash, or a literal value. The whole grid is an inline [data-compare-wrap] — no DS table class. Distinct from Pricing section, which documents the cards above it.

Cell values come straight from src/data/pricing.js (via PLANS.map) or are literal in the section config, so the matrix cannot contradict the cards above it. A cell of true renders a CheckIcon (size 16), false renders the em-dash Dash (--ins-text-disabled), and a string renders as text. The four category groups — AI & Analytics, Data connections, Semantic Layer, Support & security — each open with a mono uppercase heading row; every group after the first adds a top border.

Usage. Source src/pages/pricing.jsx (the FeatureComparison section, ~line 132) with plan names, token/connector/support values from src/data/pricing.js. Grid, borders and cell layout are inline styles in the real page — reproduced verbatim; only the section header (SectionHeader.jsx), the checks (CheckIcon.jsx) and the footer CTAs (Button.jsx → .ins-btn) are shared components.
