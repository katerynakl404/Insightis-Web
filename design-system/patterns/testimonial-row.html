Testimonial row

The real .ins-testimonial quote card, rendered by src/components/TestimonialCard.jsx. Two idioms share one class: the Solutions style (opening-quote SVG + optional company pill) and the homepage style (5-star row + corner mark + avatar).

The ::before top brand-glow line is always on; hover tints the border teal. When an avatar or initials is present the component adds .ins-testimonial--has-avatar, which switches the footer to a horizontal avatar + text row (no top border).

Classes

ClassRole
.ins-testimonialQuote card shell — dark surface, top glow line, hover border.
.ins-testimonial--has-avatarFooter becomes a horizontal avatar + name/role row.
.ins-testimonial__iconOpening-quote SVG (Solutions idiom).
.ins-testimonial__starsAmber 5-star row (homepage idiom).
.ins-testimonial__cornerDecorative “ mark, top-right.
.ins-testimonial__quoteQuote body; flexes to push the footer down.
.ins-testimonial__footerAttribution block (top border, or avatar row when has-avatar).
.ins-testimonial__name / __rolePerson / role lines.
.ins-testimonial__companyMono uppercase pill badge (Solutions idiom).
.ins-testimonial__avatar / __avatar-fallback36px avatar image, or gradient initials fallback.
