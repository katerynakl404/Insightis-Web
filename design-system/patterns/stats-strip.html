Each __value is a count-up in the real site: the prerendered HTML ships the final figure (e.g. 40,000+), so crawlers and no-JS visitors never see 0+; a layout effect resets to 0 and animates up when the strip scrolls into view (skipped under prefers-reduced-motion). This static specimen shows the resting final values.

Classes

ClassRole
.ins-stat-stripBordered surface band; 2-col grid → 4 equal columns at ≥768px.
.ins-stat-strip__itemOne centered metric cell; adds a left divider between items on desktop.
.ins-stat-strip__valueBig teal figure (36/48px), tabular, the count-up target.
.ins-stat-strip__labelMetric name line.
.ins-stat-strip__subOptional sub-label detail line.

Usage. Source src/components/StatStrip.jsx (CSS ds/components/stat-kpi.css + the .ins-stat-strip block in ds/components/card.css). Figures from the homepage strip in src/main.jsx; the About hero (src/pages/about-insightis.jsx) reuses the same component with its own numbers.
