Integrations strip

The shared "200+ Integrations" marquee strip that runs full-bleed below the hero. A fixed left label, then an auto-scrolling .marquee-left track of connector pills inside a masked .marquee-container. Each pill pairs a sprite logo (.ins-connector-logo <slug>) with its name on a --ins-surface-card pill. The real component ships Tailwind utilities + the .marquee-* animation; reproduced here with equivalent inline styles.

Class / attributeUse
.marquee-containerOverflow clip + edge-fade mask; pauses the track on hover (app-blocks.css).
.marquee-leftThe scrolling track — translateX(0 → -50%) over 30s linear infinite. Requires two identical pill sets so the wrap is seamless; the second is aria-hidden. Animation is disabled under prefers-reduced-motion.
.ins-connector-logo <slug>Sprite logo cell at --ins-connector-size:22px; slug picks the cell (salesforce, hubspot, stripe, snowflake, bigquery, postgresql, googleanalytics, zoho, quickbooks, amplitude, redshift, mysql).
var(--ins-surface-card) pill · var(--ins-border-default)Rounded pill surface and border; .ins-text-body name at 13px.

Usage. Source: src/components/IntegrationsStrip.jsx. The live component renders logos via <ConnectorIcon> from the Skyvia sprite and only shows names that resolve to a sprite cell; here the pills use the DS's .ins-connector-logo <slug> sprite classes directly with 12 real connector slugs.
