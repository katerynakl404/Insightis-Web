Screens + side tabs

Split showcase: a vertical left tab list and a right screen panel whose stacked screens cross-fade as a tab is selected. The site's "how it works" showcase on the homepage (src/main.jsx) and the questions gallery on src/pages/ai-chat.jsx both use this exact .showcase / .sc-* system.

HTML

<div class="showcase">
  <!-- LEFT: tab list. .active marks the current tab -->
  <div class="sc-steps">
    <div class="sc-step active">
      <div class="sc-lbl">Why did MRR drop last week?</div>
      <div class="sc-desc">Trial expiry without activation drove most of the drop.</div>
    </div>
    <div class="sc-step"><div class="sc-lbl">Highest pipeline drop-off?</div><div class="sc-desc">…</div></div>
  </div>

  <!-- RIGHT: stacked screens. .active is the visible one -->
  <div class="sc-preview">
    <div class="sc-panel active">
      <div class="ins-chat">
        <div class="ins-chat__bubble ins-chat__bubble--user">Why did MRR drop last week?</div>
        <div class="ins-chat__bubble ins-chat__bubble--ai">…answer…</div>
      </div>
    </div>
    <div class="sc-panel">…</div>
  </div>
</div>

storybook.js index-matches each .sc-step to the .sc-panel at the same position and toggles .active on click (Enter/Space too).

Classes

ClassUse
.showcaseGrid shell (380px tab column + fluid screen). Collapses to one column below 900px.
.sc-stepsLeft vertical tab list.
.sc-step / .sc-step.activeOne tab; .active = teal wash + revealed description.
.sc-lbl / .sc-descTab title / description (description reveals via max-height on active).
.sc-previewRight screen stage (radial teal glow bg).
.sc-panel / .sc-panel.activeOne stacked screen; only .active is shown (cross-fade).

App-level block. These .showcase/.sc-* classes live in src/app.css, not the design system — the screen content (.ins-chat, .ins-badge) is DS. They are mirrored into assets/app-blocks.css so the storybook matches the site exactly; assets/sync-ds.ps1 -Check flags app.css changes (see SYNC.md).
