The shared hero "section image" used across the six Solutions pages: a rounded dark panel with macOS window chrome, a small console/KPI mock inside, and two floating accent chips (a top-right badge, a bottom-left card). The frame dimensions (540px min-height, 24px radius, chrome, chip footprints) stay identical everywhere; the panel content, accent color and chip copy are per-page. PartFixed vs. per-page
Panel frameFixed: #0C1117 surface, 1px var(--ins-color-white-a-08) border, 24px radius, 540px min-height, var(--ins-size-6) padding.
Top accent hairlinePer-page: linear-gradient(90deg,transparent,{accentLine},transparent) — the accentLine color is a prop.
Window chromeFixed frame, per-page label: three traffic-light dots + a centered mono title.
Panel contentPer-page: the children node — chart / KPIs / funnel. Here a console line + KPI row + bar mock.
Badge / FloatCardFixed footprint (185px min-width), per-page tint: each takes an accentRgb and its own copy; rotate(2.5deg) / rotate(-2deg).

Usage. Source: src/components/HeroMockup.jsx (plus HeroMockup.Badge / HeroMockup.FloatCard). HeroMockup is a per-page illustration composed on each Solutions page — not a single fixed component: it owns only the frame and chip dimensions, while the accent color, chrome label, panel content and chip copy are passed in per page. This page shows one representative composition (marketing-teams styling).
