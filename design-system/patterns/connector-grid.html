Connector grid section

The "Your Revenue Stack" section — a SectionHeader above a 4-column .connector-card grid and a "See all 200+" pill. The same section runs on all six Solutions pages (RelevantIntegrations) and, with a category-filter toolbar, on src/pages/integrations.jsx. The card itself is documented in Connector gallery; this is the assembled labelled section.

ClassUse
[data-connectors-grid]4-col grid of connector cards (→ 2-col on tablet). Layout is inline in the JSX.
.connector-cardIcon + name + description card (src/components/ConnectorCard.jsx). Add .has-overlay for the sign-in overlay.
.ins-connector-logo <slug>Sprite-mapped logo. Connectors without a sprite fall back to a .connector-icon abbreviation box (e.g. Chargebee → CB).
.ins-eyebrow--pill + .ins-text-displayThe SectionHeader eyebrow + heading + lede above the grid.

Usage. RelevantIntegrations on all six src/pages/*-teams.jsx; the filtered variant (with a Chip variant="tab" category toolbar) on src/pages/integrations.jsx.
