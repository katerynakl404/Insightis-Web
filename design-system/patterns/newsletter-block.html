Classes

ClassUse
.ins-bottom-ctaBase organism — glow card, top brand line, responsive flex layout. Default = form variant.
.ins-bottom-cta__titleHeadline (left-aligned at ≥768px in the form layout).
.ins-bottom-cta__highlightTeal-tinted inline span for the emphasized phrase in the title.
.ins-input-groupKit rail that supplies the shared chrome (bg, border, radius, focus) for input + button.
.ins-bottom-cta__formBottomCTA-specific layout on the same element as .ins-input-group.
.ins-input .ins-bottom-cta__inputTransparent input inside the group (fixed ~280px on desktop).
.ins-btn .ins-btn--primary .ins-btn--smThe submit button nested in the rail.

Usage. Rendered by src/components/BottomCTA.jsx with variant="form" (the default; 16 page-level uses). The form posts method="get" to ctaHref; the input name defaults to q and the submit label defaults to "Start for free". Headline copy is the row-alternative documented in src/main.jsx; the metric-question example is the component's own default.
