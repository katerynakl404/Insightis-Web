Only the open row renders an .ins-faq__answer. In the real site the React component toggles .is-open and mounts/unmounts the answer on click (one row open at a time) — this static page shows the first row pre-opened. Answer copy is set via .ins-text-body on the answer element (layout only from .ins-faq__answer).

Classes

ClassRole
.ins-faqFlex column wrapper; --ins-space-sm gap between rows.
.ins-faq__rowOne Q&A card. Default white-a-06 border, rounded --ins-radius-xl.
.ins-faq__row.is-openOpen state — teal-a-30 border; rotates the chevron 180°.
.ins-faq__questionFull-width trigger button; label span + chevron, space-between.
.ins-faq__chevron18px down-chevron SVG (polyline 6 9 12 15 18 9); rotates when open.
.ins-faq__answerAnswer body layout (padding). Type comes from .ins-text-body.
