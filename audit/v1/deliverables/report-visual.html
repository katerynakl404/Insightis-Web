Insightis — UX/UI Audit v1

insightis-landing.vercel.app · dark · verified 2026-08-04 · full site (17 pages)

Method: live DOM/CSS + source (insightis-site/) + attention heatmaps + heuristic (Nielsen) + parallel source audits (component/token consistency, IA/block logic). Each finding: Now (current state) · Should be (expected) · Fix (how) · a live verify link.

74 findings — 3 Critical · 11 High · 27 Medium · 33 Low. Body text passes WCAG AA; the site's visual style is not being redesigned in v1 (proposed redesigns: fix-examples.html, pending sign-off).

Release blockers: AUD-01, AUD-02, AUD-24 (Critical); AUD-03, AUD-04, AUD-05, AUD-21, AUD-25, AUD-26, AUD-27, AUD-43, AUD-50, AUD-51, AUD-66 (High).
