Global Audit v1 — Visual Report

insightis-landing.vercel.app · Dark theme · Verified 2026-08-04 · Pages: Home, Pricing, AI Chat, Integrations, Semantic Layer

Critical · 2 High · 3 Medium · 4 Low · 3

Body text passes WCAG AA everywhere (contrast re-measured with composited translucent backgrounds). The findings below are content, navigation, accessibility, and hygiene issues — the visual style of the site is intentionally not being redesigned in v1.

AUD-01 Critical Code + DesignPricingContent

Contradictory discount: cards say 50% OFF, FAQ says save 20%

Problem
Plan cards advertise 50% OFF ($7.99 vs $15.99), while the FAQ says users "save 20% per seat." 50% ≠ 20%.
Expected
One discount figure across the page — card math and FAQ copy must agree.
Current
Card badge 50% OFF  ·  FAQ: "save 20% per seat"
Recommended
Both read the same number (e.g. 50%), matching $7.99 vs $15.99.
AUD-02 Critical Code + DesignPricingContent

FAQ references pricing tiers that don't exist

Problem
Pricing shows only Free / Starter / Pro, but the FAQ describes Team and Enterprise ("14-day free trial", "available on Team and Enterprise").
Expected
FAQ names only tiers that exist on the page — add the tiers, or remove the references.
Current
FAQ mentions Team / Enterprise; plan grid has no such cards.
Recommended
FAQ references only Free / Starter / Pro.
AUD-03 High CodeAI ChatNavigation

Broken internal link in the static fallback

Problem
platform/ai-chat.html:193 has <a href="/integrations"> → 404 (correct path is /platform/integrations). The adjacent "Start for free" points to /pricing instead of /auth/sign-up/.
Expected
Every internal link resolves. "Start for free" → sign-up.
Current
"See all integrations" → 404 page.
Recommended
Link resolves to /platform/integrations.
AUD-04 High CodeGlobalNavigation

No custom 404 page + dead route mappings

Problem
Unknown URLs render the raw Vercel 404: NOT_FOUND (no header, nav, or branding). Memory & Storage → /platform/memory-storage is mapped in Header.jsx:66 and Footer.jsx:21, but the page doesn't exist.
Expected
A branded 404 in the site's style; no mappings to non-existent pages.
Current
Raw white Vercel "404: NOT_FOUND", no branding or nav.
Recommended
Dark branded 404 with logo, teal "404", and links back into the site (already drafted in public/404.html).
AUD-05 High Code + DesignHome · Integrations · Semantic LayerContent

Numbers disagree across pages

Problem
Home: "500+ pre-built definitions" ↔ Semantic Layer: "498 built-in metrics". Home: "200+ connectors" ↔ Integrations: "20 sources".
Expected
One source of truth per metric, used consistently everywhere.
Current
500+ vs 498 · 200+ vs 20 (a 10× gap, not rounding).
Recommended
Identical figures on every page they appear.
AUD-06 Medium CodeHeader / NavAccessibility

Menu buttons lack ARIA state

Problem
Platform / Solutions / Resources have no aria-expanded or aria-haspopup (WCAG 4.1.2).
Expected
Add aria-haspopup="menu", toggle aria-expanded, verify keyboard + Esc.
Current
Screen readers don't announce that the button opens a menu or its open/closed state.
Recommended
Menu role + state announced; keyboard users get Esc-to-close.
AUD-07 Medium CodeHome · SubmenuAccessibility

Sub-44px tap targets on tabs and submenus

Problem
Team tabs ("Made for every team") and the Platform submenu are ≈18–19px tall — below 24px (WCAG 2.5.8) and far below 44px.
Expected
Increase clickable padding to ≥44px on mobile (SC 2.5.8 / 2.5.5).
Current
Cramped 18–19px targets, easy to mis-tap on mobile.
Recommended
≥44px hit area via padding (label size unchanged).
AUD-08 Medium Code + DesignDemo widgetsColor

Low-contrast functional captions in demo widgets

Problem
A few functional labels fall below AA: the Thinking state (≈2.8:1) and the "before" side of comparisons (≈2.5:1). Graphic-only captions that pass 3:1 are fine.
Expected
Functional labels ≥4.5:1 and ≥12px; add a non-color cue to the "before"/"bad" side (WCAG 1.4.1).
Current
Dim "before" label; meaning carried by color alone.
Recommended
AA-contrast labels + a marker (icon/pattern) on the "before" side.
AUD-09 Medium Code + DesignGlobalTypography

Body paragraphs default to 14px

Problem
14px dominates description paragraphs; 16px is rare. (Small 11–13px labels/badges/nav are intentional and fine.)
Expected
Raise only real description paragraphs to 15–16px — "how it works" steps, Solutions descriptions, the Devart trust line, Pricing plan features.
Current
14px description paragraphs — dense on long sections.
Recommended
15–16px body descriptions; labels untouched.
AUD-10 Low DesignHome · AI ChatContent

Repeated CTA blocks

Problem
"Get answers… not days" is duplicated; the Start for free / Explore Pricing pair repeats in nearly every section.
Expected
Vary the CTA pattern; avoid repeating the same headline + button pair per section.
Current
The same CTA pair stacked down the page.
Recommended
One primary CTA per intent, varied supporting copy.
AUD-11 Low CodeHome · Semantic LayerContent

Minor copywriting defects

Problem
Words glued together in H1 by line breaks ("Get answers in / seconds"); a double space in "Stop arguing about  which number."
Expected
Clean copy — no words glued by <br>, no double spaces.
Current
"Get answers inseconds"; "about  which".
Recommended
Correct spacing throughout.
AUD-12 Low CodeGlobalTokens

Inline <style> blocks inside <main>

Problem
Every page carries inline CSS with media queries inside <main> — a sign of hand-patched styling.
Expected
Move these into stylesheets / design-system tokens. No visual change — hygiene only.
Current
Per-page inline <style> with duplicated media queries.
Recommended
Shared token-driven styles; pages inherit.
